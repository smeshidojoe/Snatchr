# Проверка поведения

Стенды сравнивают программу **саму с собой** до и после правки. Они не говорят,
правильно ли работает код, — они говорят, изменилось ли поведение. Это ровно то,
что нужно при рефакторинге: любое расхождение либо задумано, либо это регрессия.

Сети и диска стенды не касаются, окно не открывают (`QT_QPA_PLATFORM=offscreen`),
работают за секунды.

## Как пользоваться

Перед правкой ничего делать не нужно — базовая ревизия берётся из git.

```bash
python tests/compare_with.py
```

Сравнивает текущее рабочее дерево с `HEAD`. Можно указать любую ревизию:

```bash
python tests/compare_with.py v0.9.5
```

Возвращает 0, если расхождений нет.

## Что внутри

| Стенд | Что снимает |
|---|---|
| `behavior_snapshot.py` | ~6100 строк решений: классификация 28 ссылок, 4800 команд yt-dlp (ссылка × вариант × настройки × куки × impersonate), аргументы streamlink, куки по доменам, селектор форматов на разных info, Ember (галереи, посты, счётчики), ожидаемые пути и решения о конвертации, разбор строк вывода yt-dlp, подписи площадок, все переводы на обоих языках, вырезание пиктограмм, публичный состав модулей |
| `trace_run_job.py` | Последовательность вызовов `run_job` на 25 сценариях: миниатюра, галерея (успех / отказ / сбой переноса), HLS-резка и её обрыв, Ember основной и запасной, быстрый путь и откат к полному извлечению, повтор без кук, 403 с impersonation, фолбэк секции, Vimeo, streamlink, конвертация и её падение, отмена, сбой переноса. Всё, что лезет в сеть и на диск, подменено |
| `render_history_rows.py` | 26 кадров строки истории: пять состояний, промежуточные фазы анимаций, полупрозрачная строка из каскада, галерея с одной и тремя картинками, реальная обложка, размытие при ошибке, рамка изображения, четыре темы. Сверяются попиксельно |

Каждый стенд можно запустить отдельно, он принимает путь для вывода:

```bash
python tests/behavior_snapshot.py out.txt
```

## Когда расхождения нормальны

Слепок не отличает задуманное изменение от регрессии — это делаешь ты. Меняешь
поведение осознанно (правишь баг, добавляешь формат, меняешь текст) — расхождения
будут, и их надо прочитать глазами. Меняешь только структуру кода — расхождений
быть не должно ни одного.

Полезная мелочь: состав модулей в последнем разделе `behavior_snapshot` меняется
при добавлении или удалении функций. Если в остальных разделах чисто, а тут
разница — значит, поменялась только внутренняя структура, и это ожидаемо.
